# 本机摄像头光学倍率标定

2026-11-13 对 `192.168.1.108` 的 `MediaProfile000` 主码流进行实测。摄像头型号返回
`General / IP PTZ Camera`，编码为 H.264、1280×720、25 FPS。

使用 ONVIF `AbsoluteMove` 仅移动变焦轴，再读取 `GetStatus` 并检查静止后的设备画面。
每档设备自身的 OSD `Z` 倍率与下表一致，OSD 云台方向保持 `P:65.0 T:3.1`。
这里记录的是这台设备的测量结果，其他摄像头需重新验证。

| 设备 OSD 倍率 | ONVIF 返回的绝对变焦位置 |
| --- | --- |
| 1× | 0.03333333333333333 |
| 3× | 0.1 |
| 4× | 0.13333333333333333 |
| 6× | 0.2 |
| 8× | 0.26666666666666666 |

变焦空间为 `http://www.onvif.org/ver10/tptz/ZoomSpaces/PositionGenericSpace`。
私有 `.env` 的 `CAMERA_ONVIF_ZOOM_CALIBRATION` 保存上述“倍率 → 镜头位置”映射。
原始画面和设备返回值保存在 Git 忽略的 `data/camera-calibration/`，账号密码不进入文档或报告。

`scripts/measure-camera-zoom.py --positions <位置列表>` 可重新采集明确指定的原生位置。
该工具会暂停采集和录像、采集各档画面，最后恢复原位置和原录制策略；它不自动写入标定值。
必须核对每张图中的真实设备倍率后，才能保存对应关系。测量使用项目的 `Train` 解释器。

本机自动光学循环使用 3×–8× 范围内的已标定档位，保留重点目标筛选和静止目标排除。
启动时先确认 1×，符合条件的船舶进入后由现有循环选择放大档位，离场后缩回 1×。
